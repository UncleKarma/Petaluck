# 彩色月季跨层邻接约束

版本 1.0.19 / code20；2026-11-16。

旧版仅约束同圈及生成序列相邻，不能保证内外层邻瓣不同色。新增回归测试先在旧版失败，再验证修复。

`domain/MulticolorPalette.kt` 在完整布局生成后建立邻接图：
- 每圈按实际方位角排序，连接左右相邻及首尾花瓣。
- 对外/中、中/内、外/内三组层组合，若两片花瓣的环形角距离不大于 `180/层A片数 + 180/层B片数`，视为相近位置；这相当于两片各占半个平均间距的角扇区相交。处理0/360度接缝并保留原生成序列邻接。
- 用独立种子生成八种颜色的随机候选顺序，优先给受约束最多的花瓣配色，必要时回溯，绝不放宽邻接约束。
- 同一种基础颜色仍可出现在互不邻接的位置。普通八色花、花型、UV、亮度、九种花色抽样与彩色花瓣雨不变。

验证：136主机测试通过。新增几何验证独立使用花瓣根部XY向量点积，在256种子×14片数（3584朵）上检查所有跨层近邻；原测试继续验证同圈、可复现性、普通花布局和颜色概率。开发/测试APK构建、实验API、SpatialUI、A11Y源码审计通过（样式保留既有大字号提示）。
