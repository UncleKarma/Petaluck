# 彩色月季终章 1.0.22

正常单次场景会话中，八种单色花各出现一次，颜色顺序随机；每朵花在 Ready 时记入已出现集合。之后下一朵必为彩色。调试广播仍可指定任意颜色，包括提前指定彩色；错误重试沿用原配置。会话进度目前只存在场景内存，退出应用后重新开始。

普通祝福从会话内打乱的 12 条文案中抽取；正常流程至多八次普通结尾，因此不会重复。彩色花的临时特别祝福单独存放，待确定最终文案。

彩色花末瓣松手时尝试打开 `petaluck_finale` Stage，使用 SDK `StageStyle.Mixed`（透视环境，沉浸度不可调），并把可选的花瓣雨按 24 个环绕位置持续发射。中央面板显示特别祝福和“就此别过”，点击后结束 Activity。原窗口的彩色花结尾也显示同一按钮，作为 Stage 打开失败时的退出途径。普通结尾的音乐和 15 秒花瓣雨保持原流程。

主机编译和测试能证明 API 连接及逻辑路径，不等于头显上的 Stage 打开、位置、花瓣覆盖范围和退出实际表现；这些需要实机复核。用户正在编辑的 `art/PetalRain/Sources/Scenes/PetalRain.usda` 不属于本增量。
