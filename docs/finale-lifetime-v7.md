# 彩色终章寿命延长

2026-11-18，开发版1.0.33 / code34。

Stage 粒子寿命从4秒延长到7～9秒。准备每个发射器时，使用独立随机流从3000～5000毫秒（含两端）抽取增量，加到原来的4秒上。保留八个发射器，不增加发射器数量。

**随机粒度是发射器：八个发射器分别采样，同一发射器内的粒子寿命相同。** SDK 6.2.8 的透明度关键帧按归一化寿命工作，不能用同一条曲线同时为不同寿命的粒子保持绝对1秒淡入淡出。因此本版每个发射器固定使用各自抽取的寿命，透明度关键帧设置为：

- 出生：时间0，透明度0。
- 出生后1秒：归一化时间 `1 / lifetime`，透明度1。
- 死亡前1秒：归一化时间 `1 - 1 / lifetime`，透明度1。
- 死亡：时间1，透明度0。

延长的3～5秒全部加入完全可见阶段；淡入、淡出各1秒。每秒更新发射率时不修改寿命及透明度曲线，避免影响存活粒子。

总发射率仍为每秒随机120～160片；尺寸、速度、正反随机旋转、缩小后的发射区域和单色Volume雨均不变。生命周期延长会自然增加同时存活数量。每个发射器容量192，在最长9秒、每秒20片时理论存活约180片，保留原容量。

原生测试使用7/8/9秒三个样本回读寿命，并回归发射率、运动参数、范围和模板隔离。透明度关键帧是SDK只写接口，视觉上的绝对时序、密度和性能仍需实景复测。

对全部2001个毫秒级寿命样本做浮点时序计算，淡入时长最大误差约0.00000006秒、淡出约0.00000030秒，均小于1微秒。这是关键帧计算检查，不是头显画面测量。

验证结果：139项主机测试、debug/AndroidTest构建通过；实验API检查通过，SpatialUI检查0错误/1项既有字号提示。PB311XHGKC150135G上的2项原生测试通过（95.208秒），7/8/9秒寿命回读正确，完整生产准备记录八个7～9秒内的寿命样本。已安装并确认1.0.33/code34，已发送启动命令。
